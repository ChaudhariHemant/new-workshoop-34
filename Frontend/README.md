# React To-Do App

A clean, responsive, and modern To-Do application built with React and Vite.

## Features
- ➕ Add new tasks
- ✅ Mark tasks as completed or active
- 🗑️ Delete individual tasks
- 🔍 Filter tasks by status: **All**, **Active**, and **Completed**
- 🧹 Clear all completed tasks at once
- 💾 Persistent storage using browser `localStorage`
- 🎨 Modern gradient styling and responsive layout

## Getting Started

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open the displayed local URL (usually `http://localhost:5173`) in your browser.
